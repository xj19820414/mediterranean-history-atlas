# Historical Basemaps Attribution

Source: https://github.com/aourednik/historical-basemaps

Author/maintainer: Aurelien Ourednik and contributors.

License: GPL-3.0. The upstream license is preserved in LICENSE in this directory.

Retrieved: 2026-10-07.

The world_*.geojson files are upstream snapshots, retained without coordinate edits.
The generated ../boundaries.js filters features intersecting the Mediterranean viewing window.
The original repository warns that its maps are works in progress and require independent
verification before academic use. Approximate boundaries, overlapping cultural areas,
and modern coastlines should not be interpreted as precise historical state borders.

No interpolation or annual reconstructions have been added. Selected dates after 1400
currently use the 1400 snapshot; the application displays the actual snapshot date.
